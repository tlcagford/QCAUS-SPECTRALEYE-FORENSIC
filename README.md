## 🏗️ Architecture

The entire application is contained in a **single file** (`app.py`) with:

- **Core Analyzer** - FFT computation, peak detection, artifact detection
- **Visualization Engine** - PSD wheel, raw FFT, forensic cards
- **Report Generator** - Professional PDF reports
- **Security Layer** - SSRF protection, file validation
- **Database Layer** - SQLite persistence (optional)
- **ML Layer** - Anomaly detection (optional)

## 🔬 Technical Details

### FFT Analysis
- 2D Fast Fourier Transform with configurable resolution (64×64 to 1024×1024)
- Log-magnitude scaling with CLAHE dynamic range remapping
- Peak detection with local maxima filtering
- Frequency ring labeling (f/4, f/2, 3f/4, fN)

### Deepfake Detection
- GAN upsampling artifact identification (0.25, 0.50, 0.75 frequencies)
- Spectral anisotropy analysis
- High-frequency energy anomaly detection
- ML-based anomaly scoring (Isolation Forest)

### Quality Assessment
- Focus score from high-frequency energy ratio
- Motion blur direction and magnitude
- Dead/hot pixel detection (5σ threshold)
- Texture uniformity from local spectral variance
